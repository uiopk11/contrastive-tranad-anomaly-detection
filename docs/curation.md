# 仓库整理说明

这是从实验工作区整理出的独立项目副本，原始工作区未修改。

## 纳入内容

基础 Python 实现、许可证、模型参数 JSON；12 个选择后的 notebook；历史标准输出摘要；5 份探索 CSV；重新编写的 README、方法、运行、数据和评估文档。

基础代码与另一份本地归档的相应代码逐文件核对一致，全部 17 个原 notebook 也一致。公开副本仅选择其中 12 个，未复制不完整的调参草稿、临时检查和重复绘图入口。

`source_manifest.json` 记录每个选中文件的原内容 SHA256，以及采用的整理方式。原始路径不写入公开清单。

## 整理改动

- Notebook 重命名为按用途排序的英文文件名，清除执行计数、输出、附件和个人环境元数据。
- 数据与项目路径改用 `WADI_DATA_ROOT` / `TRANAD_ROOT`；不再依赖个人目录。
- 自动 pip 安装改为显式依赖检查；环境安装由使用者主动执行。
- WADI 冻结方案去掉可选联合训练单元，避免顺序执行改变基线主干。负面联合训练方案仍由独立入口保存。
- 从源 notebook 的 stdout 提取有限的历史指标文本；图片、HTML 表格及报错堆栈不公开复制。历史文本与清理版代码的单元编号可能不同，JSON 的 `source_cell_index` 指原 notebook 索引。
- 原始传感器数据、处理数组、模型权重、个人归档文档和办公文件均未纳入。

## 验证范围

仓库检查脚本解析 Python 与 notebook 代码语法，检查 Markdown 相对链接、来源文件哈希、清理后的输出和明确禁止的个人目录信息，并检查 CSV 指标与计数的一致性。

它不会执行 notebook，不会验证模型效果，不会证明依赖兼容，也不能替代数据授权核对。已知的探索 CSV 冲突应作为警告保留；其余结构或文件检查失败应阻止发布。
