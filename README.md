# 对比学习增强的多变量时间序列异常检测

一个基于 Transformer 重构与对比表示学习的时间序列异常检测项目。以 TranAD 为基础，比较直接联合训练与冻结主干后的分数融合，并保留 WADI、SMAP 和 SMD 的实验入口、探索记录及评估说明。

## 项目内容

- **TranAD 基线**：滑动窗口、两阶段重构、自条件输入及 POT 阈值评估。
- **冻结主干的对比增强**：对正常窗口施加噪声、缩放和特征遮蔽，仅训练投影头；用表示到训练中心的余弦距离补充重构分数。
- **联合训练对照**：保留直接加入对比损失后性能下降的实验，帮助分析目标冲突和分数校准。
- **独立 Transformer 实验**：重构基线、对比损失、增强强度、特征聚合及后处理搜索。
- **可追溯文档**：说明模型、数据接口、运行顺序、指标实现和已知限制。

```text
正常时间序列 → 滑动窗口 → TranAD → 重构误差 ──────────┐
                         └→ 冻结编码器 → 投影头      │
                              ↑ 双视图 InfoNCE      │
                              └→ 训练中心余弦距离 ──┤
                                       尺度对齐 → 分数融合 → 阈值 → 异常标记
```

## 阅读与运行

先阅读 [方法说明](docs/method.md)、[运行指南](docs/reproduction.md) 和 [评估与结果边界](docs/evaluation.md)。源代码来自本地保存的 TranAD 副本；上游作者及许可证见 [第三方说明](THIRD_PARTY_NOTICES.md)。

```text
TranAD/                 基础模型、训练、预处理和 POT 实现
notebooks/              清理输出并适配路径的实验入口
results/historical/     从原 notebook stdout 提取的历史记录
results/exploratory/    保存的阈值搜索与分类汇总 CSV
docs/                   方法、数据、运行、评估和整理说明
scripts/                无需深度学习依赖的完整性检查与结果浏览
```

无需安装模型依赖即可检查仓库和阅读结果：

```bash
python -X utf8 scripts/verify_repository.py
python -X utf8 scripts/show_results.py
```

运行实验需要自行准备数据和 Python 环境；从仓库根目录启动 Jupyter，并在 `notebooks/` 中按 [运行指南](docs/reproduction.md) 选择入口。数据要求见 [数据说明](docs/data.md)。

## 已保存的观察

WADI 历史输出中的基线 PA-F1 约为 **0.6383**，冻结主干融合（α=0.10）约为 **0.6640**；利用同一测试标签搜索 α 后得到约 **0.7256**。最后一个数字属于测试集选参结果，不能当作独立测试性能。直接联合训练的一个负面案例 PA-F1 约为 **0.1091**。

SMAP 入口默认只使用 **P-1**，SMD 入口默认只使用 **machine-1-1**，并非全数据集汇总。SMAP 历史输出的基线 PA-F1 约为 0.8915，测试集搜索 α 后约为 0.8958。SMD notebook 未保存可引用的指标输出。

这些数字来自历史保存记录，本次整理未重新训练。POT 输出的 `ROC/AUC` 是对调整后二值预测计算的指标，不能解释成连续异常分数的 ROC-AUC。部分探索 CSV 存在标签或统计口径不一致，详见 [评估说明](docs/evaluation.md)。

## 当前状态

本仓库提供实验代码与项目文档。运行环境尚无完整锁定记录，历史 notebook 的执行顺序也不等于一次可验证的干净重跑。清理版修正了路径和安装副作用，但不声称精确复现历史数字，也不声称对比学习在所有数据上稳定优于基线。
